## 3. 돈 날씨 규칙
```
남은 예산 R = 월 예산 − 이번 달 지출(오늘 포함)
남은 일수 D = 월말까지 남은 날(오늘 포함)
오늘 쓸 돈 A = max(0, floor(R / D))         ← 홈 큰 숫자
오늘 지출 S
비율 r = S / A  (A=0이면 r=∞)
☀️ 맑음  r ≤ 0.7      "여유 있어요"
⛅ 흐림  0.7 < r ≤ 1.0 "딱 맞게 쓰는 중"
🌧️ 비    r > 1.0  또는 R < 0   "오늘은 쉬어가요"
```
- 예산 미설정: 날씨 대신 🌈 "예산을 정하면 돈 날씨가 떠요" 버튼.
- 무지출 데이(S=0, 하루 끝): ☀️ + 🌱 스티커, 연속 일수 🔥N.
- 내일 예보(작게): 오늘 남긴 돈이 내일 A를 얼마나 올리는지 "내일 +1,200원" 표시.

## 4. 10초 입력 흐름 (지출 기준 최소 3탭 + 숫자)
| 단계 | 사용자 행동 | 탭 | 기본값/보조 |
|---|---|---|---|
| ① | 홈 쨈 컵 기록 버튼 탭 → 시트 260ms 상승, **키패드 즉시 활성** | 1 | 종류=지출, 날짜=오늘, 결제수단=최근 사용, 키보드 대신 자체 키패드(OS 키보드 지연 제거) |
| ② | 금액 입력 (예: 1·2·0·0·0 → "12,000원") | 숫자 n | `00`·`000` 키 제공 → 12,000원 = 3탭(1,2,000), 숫자 롤링 애니메이션 |
| ③ | 카테고리 칩 탭 | 1 | **이모지 그리드 4×2**(사전조사 권고): 최근/자주 쓴 순 + 시간대 추천(아침 7~10시 ☕, 점심 11~14시 🍚 앞쪽), '더보기'로 전체 |
| ④ | `저장` 탭 (카테고리 선택 시 저장 버튼 활성·펄스) | 1 | 메모·날짜·수단은 선택 행(접힘), 수정 시에만 탭 |
| 끝 | 체크 애니메이션 + 토스트 "식비 12,000원 기록! 오늘 쓸 돈 18,400원" + `되돌리기` 5초 | — | 시트 자동 닫힘, 홈 숫자 롤링 갱신 |
- 합계: **쨈 컵 기록 버튼 1 + 숫자 3 + 카테고리 1 + 저장 1 = 6탭, 실측 목표 5~8초**.
- 수입: 시트 상단 세그먼트 `지출 | 수입` 1탭 추가.
- 고급: 저장 버튼 길게 누르기 = 반복 거래 등록. 같은 날 같은 카테고리·금액 연속 입력 시 "혹시 중복인가요?" 확인.
- 하드웨어 키보드(PC): 숫자 직접 입력, Enter=저장, Esc=닫기, 1~5 = 추천 카테고리.

## 5. 화면 목록
1. **홈**: 상단(월 선택 `10월 ▾`, 테마 토글, 설정) → 홈 상단 카드(돈 날씨 아이콘·문구, "오늘 쓸 수 있는 돈" display 숫자, 이번 달 예산 진행 바 `83% 사용`) → 3열 미니 통계(이번 달 지출/수입/**남긴 돈(저축)** — 사전조사: 저축이 안 보인다는 공통 불만) + 연속 기록 🔥 배지 → 최근 거래 3개(이모지·이름·메모·금액, 팁 말풍선이 내용을 가리지 않도록 3개로 제한) → 구석 팁 말풍선 → 하단 탭바(홈·달력·차트·예산) + 중앙 쨈 컵 기록 버튼.
2. **입력 시트**: 핸들, 지출/수입 세그먼트, 큰 금액(롤링), 추천 카테고리 칩, 접힌 옵션 행(📅 오늘 · 💳 카드 · ✏️ 메모), 3×4 키패드(1–9, 000, 0, ⌫), 저장 버튼.
3. **목록·달력**: 월 헤더(◀ 10월 ▶), 요일 행, 날짜 칸(지출 합계 micro, 지출 많을수록 진한 파스텔 히트맵 4단계, 무지출 🌱), 선택일 거래 목록. 상단 토글 `달력 | 목록`.
4. **차트**: 카테고리 도넛(가운데 총지출) + 범례 순위, 6개월 추이 막대, "지난달보다 ☕ 카페 +18%" 인사이트 카드.
5. **예산**: 월 총예산 링(Monarch식), 카테고리별 봉투 바(YNAB식, 초과 시 expense색 + "넘쳤어요"), 남은 일수·하루 권장액.
6. **설정**: 카테고리 편집, 결제수단, 월 시작일, 다크모드(시스템/라이트/다크), CSV 내보내기·가져오기(M2), 팁 다시 보기, 계정 삭제.

## 6. 마이크로 애니메이션
> 선생님 지시(2026-10-26): 추가 버튼은 호텔 조식의 작은 쨈 컵. 누르면 '탁' 터지며 0.3~0.6초 안에 쨈으로 바뀌고, 움직임 줄이기를 존중한다. 호일 위 '쨈' 글자는 쨈 맛 색으로 달달·통통하게(방울·윤기), 작은 크기에서도 읽힌다. 시안 3개씩 먼저 보고 고르는 방식으로 진행해 시안 D(극사실 호일 컵)를 골랐다. 누를 때 말랑이 같은 손맛, 설정을 따르는 '뽁'·'톡' 소리와 짧은 진동.

| 이름 | 트리거 | 시간 | 이징 | reduced-motion |
|---|---|---|---|---|
| 숫자 롤링 | 금액 변경·홈 갱신 | 420ms, 자릿수별 30ms 지연 | `cubic-bezier(.2,.8,.2,1)` | 즉시 교체 |
| 시트 상승 | 쨈 컵 버튼 탭 | 280ms 열기 / 200ms 닫기 | `cubic-bezier(.32,.72,0,1)` (iOS 시트) | 페이드 120ms |
| 쨈 컵 버튼 누름 | pointerdown·Enter·Space | 누르는 동안 70ms 만에 scale(1.1,.86)로 눌린 채 → 놓으면 460ms 되튐 | `cubic-bezier(.28,1.9,.42,.9)` (말랑이 되튐) | 눌림 없음 |
| 쨈 컵 '탁' | 탭 | 520ms: 컵 눌림 → 호일 벗겨짐 → 쨈 방울 → '쨈' 글자 뛰어오름 → 제자리, 시트는 250ms에 열림(연타해도 한 번, 연출 중 닫고 다시 누르면 바로 열림, 올라오는 300ms 동안의 누름은 무시) | `cubic-bezier(.3,1.5,.5,1)` | 움직임 없이 접시에 쨈 색이 160ms 옅게 덮였다 사라짐(애니메이션이 아닌 색 전환이라 전역 0.01ms 규칙과 무관), 시트 바로 |
| 키 탭 리플 | 키패드 | 300ms | `ease-out` | 배경 깜빡임 80ms |
| 카테고리 선택 | 칩 탭 | 180ms scale 1→1.08→1 | `cubic-bezier(.34,1.56,.64,1)` (튀는) | 없음 |
| 저장 체크 | 저장 | 체크 그리기 360ms + 시트 닫힘 | `ease-in-out` | 체크만 표시 |
| 날씨 아이콘 | 홈 진입 | ☀️ 회전 흔들 6s 무한 / 🌧️ 빗방울 1.2s | `ease-in-out` | 정지 |
| 진행 바 채우기 | 홈 진입 | 700ms | `cubic-bezier(.2,.8,.2,1)` | 즉시 |
| 팁 말풍선 | 등장/교체 | 240ms 페이드+4px 상승 | `ease-out` | 페이드만 |
| 토스트 | 저장 후 | 등장 220ms, 3.5초 유지 | `ease-out` | 동일(이동 없음) |
| 오로라 배경 | 상시 | 20s 천천히 이동 | `linear` | 정지 |

8. 거래를 왼쪽으로 밀면 바로 지울 수 있어요. 실수해도 되돌리기가 있어요.
9. 카테고리 이름과 이모지는 설정에서 내 마음대로 바꿀 수 있어요.

11. 카드사 엑셀 파일을 끌어다 놓으면 한 번에 들어와요. (곧 지원)

13. 홈 화면에 추가하면 앱처럼 바로 열려요.
14. 월급날이 25일이라면, 설정에서 한 달 시작일을 25일로 바꿔 보세요.

16. 밤에는 다크 모드가 눈에 편해요. 오른쪽 위 🌙를 눌러 보세요.
17. 예산을 정하면 오늘 쓸 수 있는 돈이 자동으로 계산돼요.

## 9. 접근성
- 대비: 1-1 표 모든 텍스트 쌍 4.5:1 이상(계산값 표기). 홈 상단 카드 흰 글자는 그라데이션 최밝은 지점에서 오버레이+그림자로 보정, 숫자는 40px 굵게(큰 글자 기준 3:1 이상 확보).
- 색 외 단서: 부호(±), 날씨 이모지 + 텍스트 라벨 병기.
- 이모지에 `aria-hidden`, 카테고리는 텍스트 라벨로 읽힘. 금액은 `aria-label="지출 12,000원"`.
- 포커스 링 `2px solid primary, offset 2px`. 시트는 `role="dialog" aria-modal`, 포커스 트랩, Esc 닫기.
- 글자 크기 200% 확대 시 레이아웃 유지(rem 사용), 터치 44px 이상, 다크모드는 `prefers-color-scheme` 기본 추종.

**피할 것 (디자인 금지 규칙)**
1. 홈에 카드 5장 초과 금지 — 상세는 눌러서(점진적 공개). 탭은 4개+쨈 컵 기록 버튼로 고정.
2. 광고 영역·마케팅 알림·필수 마케팅 동의 없음. 알림은 기본 꺼짐, 켜도 하루 1회 '돈 날씨' 요약만.
3. 자동 연동/스크래핑 UI 없음(아이디·비밀번호 입력란 금지).
4. 제로베이스 강제 금지 — 기본은 '월 총예산 하나', 카테고리 봉투는 선택(예산 화면 `카테고리별로 나누기` 토글).
5. 카테고리는 이름·이모지·순서·숨김 모두 2탭 내 편집, 삭제 시 거래는 '기타'로 이동(데이터 보존).
6. 44px 미만 버튼, 13px 미만 본문 금지(달력 칸 micro 11px 예외).
7. 카드번호·계좌번호 입력/표시 금지, 원본 파일 업로드 없음(가져오기 화면에 "파일은 이 기기 밖으로 나가지 않아요" 고정 문구).

## 11. (M2) CSV/엑셀 가져오기 화면
카드사 양식은 **신한·현대 일부만 확인**(사전조사 2절) → 특정 양식에 의존하지 않고 "자동 추정 + 사람이 확인·수정" 구조. 설정 > 가져오기, 또는 PC에서 앱 어디든 파일 드래그 시 진입. 4단계 스테퍼(상단 ●●○○).

**① 파일 드롭**
- 큰 점선 드롭존(반경 lg, 높이 200): 📥 "카드사·은행에서 받은 엑셀(.xls, .xlsx)이나 CSV를 끌어다 놓으세요" / [파일 고르기]. 하단 고정: 🔒 "파일은 이 기기 밖으로 나가지 않아요. 원본은 저장하지 않아요."
- 처리(구현 메모): SheetJS → 실패 시 HTML 표로 재시도(현대 .xls=HTML 사례) · CSV는 UTF-8 → 한글 깨짐 감지 시 EUC-KR 재디코딩 · 상위 10행 스캔해 '일자/일시/이용일' + '금액' 함께 있는 첫 행을 헤더로.
- 진행: 스켈레톤 표 + "표를 읽고 있어요…". 오류: "이 파일은 읽을 수 없었어요. 엑셀에서 'CSV(쉼표로 분리)'로 다시 저장해 보세요." / 시트 여러 개면 시트 선택 칩.

**② 컬럼 매핑 미리보기 (핵심)**
- 상단: 감지 결과 칩 `현대카드 형식 같아요 ✓`(프리셋 일치 시, 아니면 `일반 형식`) · `인코딩 EUC-KR` · `헤더 3행` — 각 칩 탭으로 수정(헤더 행 ±, 인코딩 전환).
- 본문: **원본 첫 5행 표**(가로 스크롤, 첫 열 고정). 각 열 머리 위에 드롭다운 `날짜 / 금액 / 내용(가맹점) / 출금액 / 입금액 / 메모 / 무시`. 자동 추정된 열은 primary 테두리 + "자동" 배지, 사용자가 바꾸면 배지 사라짐. 필수(날짜·금액 또는 출금/입금 쌍) 미지정 시 해당 슬롯 빨간 점 + "금액 열을 골라 주세요".
- 옵션 행: 날짜 형식(자동: `2026.10.03` 등 표본 표시) · 금액 부호 `양수=지출 / 양수=수입 / 뒤집기` · `입금·출금 열이 따로 있어요` 토글 · `상태가 '취소'인 행 제외` 토글(기본 켬) · 결제수단 지정(💳 신한카드 등, 끝 4자리 이하만).
- 하단: 변환 결과 미리보기 5행(우리 앱 형식: 날짜·이모지 카테고리·내용·금액). 카테고리는 규칙(가맹점→카테고리) + 키워드 추정, 못 찾으면 🧾 기타(흐린 표시).
- "이 매핑 기억하기" 체크(기본 켬) → 다음에 같은 헤더면 ②를 자동 통과하고 확인만.

**③ 중복 감지**
- 기준: 승인번호 일치 → 확실 중복 / 날짜 같고 금액 같고 가맹점 유사도 ≥0.8 → 중복 의심 / 파일 내부 중복도 검사.
- 요약 카드: "새 거래 **128건** · 중복 의심 **6건** · 제외(취소) **3건**". 의심 건 목록: 왼쪽 '이미 있는 기록', 오른쪽 '가져올 행' 나란히, 행마다 `건너뛰기(기본) / 그래도 추가` 세그먼트. 일괄 `모두 건너뛰기`.

**④ 확정**
- 요약 + 기간(10.01~10.31)·합계 지출/수입 표시, [128건 가져오기] 버튼(primary, 전체 폭).
- 완료: 체크 애니메이션 + "128건 가져왔어요. 분류를 고치면 다음부터 알아서 맞춰 둘게요." [되돌리기](이번 가져오기 묶음 전체 삭제, 24시간 내) · 거래마다 `importHash` 저장.
- 이후 분류 수정 시 토스트 "앞으로 '스타벅스'는 ☕ 카페로 분류할까요? [그렇게 하기]" → 규칙 자동 생성(Actual 방식).
- 접근성: 표는 `<table>` + `<th scope>`, 드롭다운은 네이티브 `<select>`, 스테퍼는 `aria-current="step"`.
- 검증 필요: 신한/현대 외 카드사 프리셋은 실제 샘플(개인정보 가린 것)로 확인 전까지 '일반 형식'으로만 동작.

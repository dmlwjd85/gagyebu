# 데이터 보안(플레이) · 앱 개인정보(앱스토어) 답안

코드 기준(2026-11-14). 광고·분석 SDK 없음. Firebase 인증·Firestore 만 사용.

| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하나요? | 예 |
| 전송 중 암호화 | 예(HTTPS) |
| 삭제 요청 방법 | 예. 앱 안 + https://dmlwjd85.github.io/gagyebu/delete-account.html |
| 제3자와 공유 | 아니요(Google Firebase 는 서비스 제공업체로, 공유에 해당하지 않음) |

**수집 항목**(모두: 필수, 목적 = 앱 기능·계정 관리, 광고·분석 목적 아님)

| 유형 | 내용 |
|---|---|
| 개인 정보 > 이름, 이메일 주소, 사용자 ID | Google 로그인 |
| 금융 정보 > 기타 금융 정보 | 사용자가 직접 적은 수입·지출, 예산, 주식·연금 보유 내역 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 | 메모·태그, 카테고리 이름 |

수집하지 않음: 위치, 연락처, 문자(붙여 넣은 문자는 기기에서만 처리), 사진, 기기 ID, 결제 정보(카드번호 전체는 저장을 거절), 건강.

**앱스토어 개인정보 라벨**: '사용자에게 연결된 데이터' = 연락처 정보(이메일·이름), 식별자(사용자 ID), 금융 정보(기타), 사용자 콘텐츠. 추적 = 없음.

**콘텐츠 등급 설문**: 폭력·성·도박·약물 없음, 사용자 간 소통 없음, 위치 공유 없음 → 전체이용가 예상.

## 2. 플레이 스토어에 올리는 순서

1. **개발자 계정** 만들기(25달러, 한 번). 개인 계정은 본인 확인과 기기 인증이 필요합니다.
2. **앱 껍데기 만들기** (Node 18+, JDK 17 이 있는 PC)
   ```bash
   npm i -g @bubblewrap/cli
   cd store/android
   bubblewrap init --manifest https://dmlwjd85.github.io/gagyebu/manifest.webmanifest   # 물으면 twa-manifest.json 값과 같게
   bubblewrap build        # app-release-bundle.aab 가 나옵니다
   ```
   - 패키지 이름 `io.github.dmlwjd85.gagyebu` 는 **한 번 올리면 바꿀 수 없습니다.** 바꾸려면 올리기 전에.
   - `android.keystore` 와 비밀번호는 저장소에 올리지 말고 따로 보관(.gitignore 에 넣어 둠). 잃어버리면 업데이트를 못 올립니다.
   - 대상 API 는 36 이상이어야 합니다(2026-08-31 부터 새 앱 필수). `bubblewrap doctor`·최신 버전으로 맞추세요.
3. **주소창 없애기(디지털 애셋 링크)**: 플레이 콘솔 > 앱 무결성 > 앱 서명에서 **SHA-256 지문**을 복사해
   `dmlwjd85/dmlwjd85.github.io` 저장소(사이트 뿌리)의 `.well-known/assetlinks.json` 에 넣습니다. 틀은 `assetlinks.template.json`.
   - 주소는 꼭 `https://dmlwjd85.github.io/.well-known/assetlinks.json` 이어야 합니다(gagyebu 저장소 안에 두면 안 읽힘).
   - 그 저장소 뿌리에 빈 `.nojekyll` 파일이 있어야 점(.)으로 시작하는 폴더가 배포됩니다.
   - 지문은 업로드 키 것과 플레이 앱 서명 것 **둘 다** 넣습니다.
4. **비공개 테스트**: 새 개인 계정은 테스터 12명이 14일 동안 참여해야 정식 출시를 신청할 수 있습니다.
5. 스토어 등록정보·데이터 보안·콘텐츠 등급 입력: `play-listing.md`, `data-safety.md`.
6. 심사용 로그인: Google 로그인만 있으므로 **심사용 Google 계정**(아이디·비밀번호)을 '앱 액세스 권한'에 적어야 합니다. 2단계 인증이 꺼진 전용 계정을 하나 만드세요.

## 3. 비공개 테스트에서 먼저 볼 것

- [ ] 앱에서 'Google로 시작하기' → 로그인되고 앱으로 돌아오는가(팝업이 막히면 리다이렉트로 넘어가는데, github.io 주소에서는 리다이렉트 로그인이 실패할 수 있음. 안 되면 로그인 도우미를 같은 주소로 옮기는 작업이 필요)
- [ ] 주소창이 보이지 않는가(보이면 3번 지문이 틀린 것)
- [ ] 비행기 모드에서 기록 → 다시 연결하면 올라가는가
- [ ] 뒤로 가기로 앱이 엉뚱하게 닫히지 않는가
- [ ] 파일 가져오기(엑셀·CSV)·CSV 내보내기·리포트 공유가 되는가
- [ ] 설정 > 모든 기록과 계정 삭제가 끝까지 되는가

## 4. 스토어 입력값

- 카테고리: 금융 / 광고 없음 / 인앱 결제 없음 / 대상 연령: 13세 이상 구간만(13세 미만 선택 안 함)
- 금융 기능 선언: 대출·투자 중개·송금 같은 금융 서비스를 제공하지 않는 **개인 가계부**입니다. 양식에서 해당 기능 없음으로 선언합니다(양식 문구는 올릴 때 확인).
- 개인정보처리방침·계정 삭제 주소는 위 표의 두 주소.

## 5. 출시 전에 정해야 할 것: 시세 자동 갱신

`sync-prices` 는 **모든 사용자**의 보유 종목을 읽어 금융위원회 시세(공공누리 4유형: 출처 표시·비상업·변경 금지)를 각자 문서에 써 줍니다.
혼자 쓸 때는 문제가 없지만, 스토어로 여러 사람에게 내보내면 '제3자 제공'에 해당할 수 있습니다(README 에도 재배포 불가로 적어 둠).

- 가: 공공데이터포털 활용신청 조건을 확인하고 유지(무료·광고 없음 유지, 화면에 출처 표시는 이미 있음)
- 나: 출시판에서는 자동 갱신을 끄고 가격은 직접 입력만(가장 안전)
- 다: 재배포가 허용되는 다른 시세 출처로 바꾸기

정하기 전까지는 '나'를 권합니다. 저장소 시크릿 `DATA_GO_KR_KEY` 를 지우면 꺼집니다.

## 6. 그 밖에

- 이 문서와 처리방침은 변호사 검토를 받은 것이 아닙니다. 처리방침의 운영자 이름은 '쨈 가계부 운영자'로 적었습니다. 플레이 스토어는 개발자 이름(개인은 실명)과 문의 이메일을 공개합니다.
- 화면에 새로 저장하는 정보가 생기면 `public/privacy.html` 과 `data-safety.md` 를 같이 고칩니다.

# 아이폰(앱스토어) 계획 — 다음 단계

지금 코드 그대로는 앱스토어에 올릴 수 없습니다. 필요한 것:

1. **Mac + Xcode, Apple 개발자 프로그램(연 99달러)**. 윈도우만으로는 빌드·제출을 못 합니다.
2. **앱 껍데기**: Capacitor 로 iOS 프로젝트 만들기. 플레이의 TWA 같은 방식이 iOS 에는 없습니다.
3. **로그인 다시 만들기**
   - 앱 안 웹뷰에서는 Google 이 로그인을 막습니다(disallowed_useragent). 네이티브 Google 로그인 플러그인으로 바꿔야 합니다.
   - Google 로그인을 쓰면 **'Apple로 로그인'도 함께** 넣어야 합니다(심사 지침 4.8). Firebase 에 Apple 제공업체를 켜고, 계정 삭제 때 Apple 토큰 해지도 해야 합니다.
4. **심사 지침 4.2(최소 기능)**: 웹사이트를 감싼 것만으로 보이면 거절될 수 있습니다. 오프라인 기록, 파일 가져오기·공유 같은 앱다운 기능을 심사 메모에 적고, 가능하면 네이티브 기능(예: 공유 시트, 햅틱)을 붙입니다.
5. 이미 갖춘 것: 앱 안 계정 삭제(5.1.1(v)), 처리방침 주소, 개인정보 라벨 답안(`data-safety.md`), 광고·추적 없음.

순서 제안: 플레이 비공개 테스트로 로그인·오프라인을 먼저 검증 → Capacitor 가지에서 로그인 2종 작업 → TestFlight.
